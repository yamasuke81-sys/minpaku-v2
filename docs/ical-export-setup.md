# iCal 書き出し（直販予約 → OTA 自動ブロック）セットアップ手順

直販（自社サイト等）の確定予約を iCal フィードとして配信し、Airbnb / Booking.com に取り込ませて
該当日程を自動ブロックさせる機能のセットアップ手順。

## 仕組み

- 配信URL: `https://api-5qrfx7ujcq-an.a.run.app/public/ical/<トークン>.ics`（物件 × プラットフォーム毎に発行）
- 配信内容: **直販予約のみ**（`bookings` の `source:"direct"` かつ `status:"confirmed"`）。
  Airbnb⇄Booking.com 間の相互ブロックは既存のクロスインポート設定を維持する（v2 障害時も OTA 間ブロックが生き続けるため）
- 個人情報は含めない（SUMMARY は "Reserved" 固定）
- トークンは `icalFeeds/{token}`。URL が漏れた場合は物件編集モーダルから再生成（旧URLは即時無効化）

## 手順

### 1.【PC】配信URLを発行する

1. 管理アプリ → 物件管理 → 対象物件の編集モーダルを開く
2. 「iCal 書き出し（直販予約 → OTA 自動ブロック）」セクションで Airbnb / Booking.com それぞれ「発行」
3. 表示された URL をコピー

### 2.【PC】Airbnb に登録する

1. https://www.airbnb.jp/hosting/listings → 対象リスティング → カレンダー
2. 「空室状況」→「カレンダーを接続」→「別のウェブサイトに接続」
3. コピーした URL（airbnb 用）を貼り付け、名前を「直販 (minpaku-v2)」等にして保存
4. 「今すぐ同期」で初回同期を実行

※ Airbnb の自動同期は **3時間ごと**。

### 3.【PC】Booking.com に登録する

1. https://admin.booking.com/ → 対象施設 → 「料金と空室状況」→「カレンダーの同期」
2. 「カレンダー接続を追加」→ コピーした URL（booking 用）を貼り付けて保存
3. 「Import now」で初回同期を実行

※ Booking.com の自動同期は **1〜2時間ごと目安**。
※ iCal 同期が使えるのは「部屋タイプ20以下・各部屋タイプ1ユニット」の施設のみ。
※ 登録後に Booking.com のカレンダーを手動で開閉するとインポート内容を上書きするので避ける。

### 4. 動作確認

1. テスト用の直販予約（`source:"direct"`, `status:"confirmed"`）を作成
2. 物件編集モーダルの「最終取得」時刻が更新されることを確認（OTA が取得した証拠）
3. Airbnb / Booking.com のカレンダーで該当日程がブロックされることを確認（手動同期で前倒し可）
4. テスト予約を削除（またはキャンセル）→ 次回同期でブロックが解除されることを確認

## 監視

- 朝のブリーフィングが「一度でも取得されたフィードが48時間以上未取得」を検知すると 🔴 警告を出す
- 物件編集モーダルの各フィード行に OTA 側の最終取得時刻を表示

## 注意（ダブルブッキング対策）

iCal 同期には1〜3時間のラグがあるため、直販側は**リクエスト承認制**を維持すること
（承認までの時間が同期ラグの緩衝材になる）。承認前に必ず管理アプリのスケジュールで空きを確認する。
